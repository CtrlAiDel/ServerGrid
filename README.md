# ServerGrid

**Author:** WeConnected  
**Version:** 2.1.0  
**Platform:** BetterDiscord  

**ServerGrid** is a BetterDiscord plugin that adds a **Serv** button to your Discord interface, opening a full-page grid view of all your servers and folders. Organize your server list effortlessly with intuitive drag-and-drop controls.

---

## ✨ Features

* **Full-Page Grid View:** View all of your joined servers and folders in one clean, expansive layout.
* **Drag-and-Drop Organization:** Reorder servers, group servers together to create new folders, and move servers in and out of existing folders with ease.
* **Persistent Layout & Settings:** Automatically remembers your custom server order, layout configuration, open/closed folder states, and hidden items across restarts.
* **Quick Access:** Open and close your grid anytime using the dedicated **Serv** button.

---

## 📥 Installation

1. Download `ServerGrid.plugin.js`.
2. Open Discord and go to **User Settings** (the gear icon near the bottom left).
3. Scroll down to the **BetterDiscord** section and click on **Plugins**.
4. Click **Open Plugins Folder** at the top of the page.
5. Drag and drop `ServerGrid.plugin.js` into the folder that opens.
6. Return to Discord and toggle **ServerGrid** ON in your Plugins list.

---

## 🚀 Usage

1. Click the **Serv** button added to your Discord UI to launch the full-page grid.
2. **Reorder:** Click and drag any server or folder to reposition it on the grid.
3. **Create a Folder:** Drag one server directly onto another server to group them into a new folder.
4. **Manage Folders:** Drag servers into existing folders to add them, or drag them out to remove them.
5. Close the grid view whenever you're done to jump straight into your selected server.

---

## 🛠️ Troubleshooting

* **The plugin isn't showing up:** Make sure BetterDiscord is up to date and that `ServerGrid.plugin.js` is saved directly inside the `plugins` folder (not inside a subfolder).
* **Layout conflicts:** If you use custom CSS themes or other plugins that heavily modify the server sidebar, try disabling them temporarily to check for styling conflicts.
